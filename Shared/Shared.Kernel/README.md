# Shared.Kernel

Shared kernel package for the DirectoryService project.

## Versioning

This package follows [Semantic Versioning (SemVer)](https://semver.org/) with the following guidelines:

- **MAJOR** — breaking change in the public API (e.g., renaming/removing a factory)
- **MINOR** — new functionality that is backward compatible
- **PATCH** — bug fix without API changes

### Release Process

For each release:
1. Create a git tag `vX.Y.Z` in the repository
2. Include a link to the commit in the release notes
